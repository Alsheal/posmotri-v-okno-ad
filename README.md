# Проект «Посмотри в окно»

## Описание проекта

**«Посмотри в окно»** — веб-страница с видеотрансляциями городов в разное время суток. Пользователь может найти видео по названию города и времени суток, переключаться между карточками и просматривать выбранный ролик.

Проект выполнен с использованием **HTML и CSS**. JavaScript-логика приложения предоставлена в готовом виде.


## Что было сделано

### 1. Общий лейаут страницы

- Страница центрирована по горизонтали и вертикали с помощью Flexbox.
- Контент разделён на две колонки: видеоблок с формой поиска и заголовок со списком карточек.
- Колонки выровнены по нижнему краю контейнера, между ними задан отступ.
- Правая колонка растянута на оставшуюся ширину и высоту.
- Для списка карточек задана фиксированная высота и вертикальная прокрутка.

### 2. Размеры и расположение элементов

- Настроены размеры видеоблока и отступ до формы поиска.
- Для видео задано `object-fit: cover`.
- Настроены отступы между карточками и до кнопки «Показать ещё».
- Карточки расположены в строку: текстовая часть слева, изображение справа.
- Для изображений заданы фиксированная высота, минимальная ширина, `object-fit` и `object-position`.
- Текстовый контейнер растягивается с помощью `flex-grow` и использует `min-inline-size: 0` для корректного обрезания содержимого.

### 3. Оформление текстов

- Заголовки полей формы получили необходимые размеры, начертание и отступы.
- Главный заголовок оформлен шрифтом Oswald, с использованием крупного размера, плотного `line-height` и `text-transform: uppercase`.
- Акцентная часть заголовка «По-» выделена серым цветом.
